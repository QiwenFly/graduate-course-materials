# README
研究生课程资料

## （1）前言

本仓库由25级软件工程专硕李春阳整理，收录研究生阶段的课程资料、作业示例与个人学习经验，希望帮助师弟师妹减少信息差，在选课和学习过程中少走一些弯路，获得更高的分数。

资料主要来自本人修课经历及往届同学的分享，课程说明带有个人主观感受，仅供参考。不同年级、授课教师的课程安排与考核方式可能有所不同，请以当年的实际要求为准。

欢迎大家补充资料、纠正错误，分享自己的学习经验，一起维护这个仓库。
